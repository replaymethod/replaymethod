# Replay Method project memory

Before changing this project, read [`docs/MASTER_PRODUCT_BRIEF.md`](docs/MASTER_PRODUCT_BRIEF.md).
It is the durable source of truth for product direction, commercial decisions,
quality standards, delivery rules and the agreed build order.

When a new product decision is made:

1. implement it when the owner has asked to proceed;
2. update the master brief if it changes scope, positioning, pricing or roadmap;
3. run the relevant checks;
4. update GitHub and the live Sites deployment for completed website batches,
   unless the owner explicitly asks for a draft or local-only experiment;
5. never claim that an idea is live, automated or validated before it is.

Preserve evidence-first coaching, explicit abstention and the protected-main
workflow. Do not weaken detector accuracy, privacy or truthful marketing for a
faster launch.
